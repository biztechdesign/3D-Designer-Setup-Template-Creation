Apparel Artwork Templates

How to create ready-made artwork (SVG) that shoppers personalise on t-shirts, hoodies and other apparel. There are no 3D files: you only supply the artwork. Every template follows the structure of our reference file, Baby Shower.svg.

1Before you start

A template is one SVG made of two parts: live text the shopper can change, and flat vector shapes that make up the artwork. The garment colour shows through everywhere else.

  1. Canvasprint-area ratio
  2. Draw artworkflat colours
  3. Group itTEXT + SHAPES
  4. Merge pathsone per colour
  5. Save & checktext editor

One template fits one print area. For a design on the front and the back, make one SVG for each and name them as a pair (baby-shower_front.svg, baby-shower_back.svg).

2Prerequisites and required settings

Software

  • Adobe Illustrator for designing.
  • A text or code editor (VS Code, Notepad++) to check the saved SVG.

Settings to use every time

Top-level groupsTEXT and SHAPES

3Create the artwork SVG

  1. Set the canvas. File → New, units Pixels, in the proportions of the print area. The reference is 720 × 1080 px (2 : 3, portrait), which suits a full front or back. Use Color Mode RGB.
  2. Draw with flat colours only. Every shape is a solid fill. Leave the background empty so the garment colour shows. Keep the design within the canvas with a small margin all round.
  3. Put all text in one TEXT layer. Each line is its own live text object (YOUR TEXT HERE, BABY, SHOWER), so shoppers can edit each one. Don't outline text.
  4. Put all artwork in one SHAPES layer, split into one sub-group per element: OTHER_SHAPS, SHIRTS_AND_ROPES, L_BALLOON, R_BALLOON, BABY_CART. Illustrator saves each group name as the id (spaces become underscores) and keeps the original in data-name.
  5. Merge each group into one path per colour. Select everything of one colour in a group and choose Object → Compound Path → Make (Ctrl+8). In the reference file each balloon group has 5 paths, one per colour, and the whole file has only 24. Stay under 300 paths.
  6. Remove what isn't allowed. No gradients, mesh gradients, clipping masks (clipPath), opacity masks, placed images, effects or shadows. Expand appearance and strokes into plain fills.
  7. Save. File → Save As → SVG, then More Options: SVG 1.1, Preserve Illustrator Editing Capabilities off, CSS Properties = Presentation Attributes (so colours are saved as fill="…", like the reference). Leave Responsive ticked; the reference has only a viewBox.
  8. Check it in a text editor. Compare it with the reference structure below. 
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 720 1080">
  <g id="TEXT">
    <text transform="translate(235.17 463.16)" font-size="93.72" fill="#fff"
          font-family="DINRoundPro-Black, DIN Round Pro" font-weight="800">BABY</text>
  </g>
  <g id="SHAPES">
    <g id="L_BALLOON" data-name="L BALLOON">
      <path d="M…Z" fill="#49bce9"/>
      <path d="M…Z" fill="#ed4b67"/>
    </g>
  </g>
</svg>

4Guidelines, limitations and recommendations

ItemLimit or rule
PathsAt most 300 per file
StructureTEXT + SHAPES, with named artwork groups inside SHAPES
ColourFlat fills only; no gradients or mesh
Not supportedclipPath, masks, images, filters, shadows, <style> tag
TextLive, one <text> per line, fonts from the designer font list
Fine detailLines at least 1 pt thick, text at least 8 pt, or it may not print cleanly on fabric

Recommendations

  • Open Baby Shower.svg and copy its structure for every new design.
  • Use a few solid colours that work on both light and dark garments.
  • Name artwork groups by what they are (L_BALLOON, BABY_CART), not Group 12.
  • Don't use team crests, brand logos or characters unless you have the rights to them.
